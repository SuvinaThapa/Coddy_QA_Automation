# Cody QA Testing and Automation

## About the Project

This repository contains my QA testing and test automation work for the Cody application.

Website under test: [https://demo.coddypro.com/]

The project covers test case design, functional and non-functional testing, positive and negative testing, edge cases, bug reporting, and Selenium automation.

## Testing Scope

The application will be tested across 5 main modules.

The testing will cover:

* Functional testing
* Non-functional testing
* Positive test cases
* Negative test cases
* Edge cases
* Test case design
* Bug reporting
* Selenium automation

## Test Cases

Test cases will be created for each module and will include:

* Test Case ID
* Test Scenario
* Preconditions
* Test Steps
* Test Data
* Expected Result
* Actual Result
* Status
* Priority
* Severity

## Bug Reporting

Bugs found during testing will be documented with details such as:

* Bug ID
* Bug Title
* Module
* Steps to Reproduce
* Expected Result
* Actual Result
* Severity
* Priority
* Status
* Screenshots or other evidence

## Automation

Selected test cases will be automated using Selenium.

The automation code will focus on important user workflows and will be organized using the Page Object Model approach.

## Tools Used

* Python
* Selenium
* Pytest
* Git
* GitHub
* VS Code

## Project Status

Testing and automation are currently in progress.

Test cases, bug reports, test results, and automation scripts will be added to this repository as the project progresses.
